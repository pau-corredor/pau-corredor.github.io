🚕 Urban Routes — QA Manual Tester

Descripción del proyecto:
Aplicación web de planificación de rutas que calcula duración y precio de viajes para diferentes tipos de transporte (automóvil personal, taxi, bicicleta, scooter, a pie y automóvil compartido).

Problema a resolver:
Garantizar la calidad y funcionalidad de una aplicación crítica de transporte antes de su lanzamiento, identificando errores que podrían afectar la experiencia del usuario y la reputación de la empresa.

Actividades realizadas:

  • Análisis de requisitos mediante mapas mentales y diagramas de flujo
  • Diseño de casos de prueba utilizando clases de equivalencia y valores límite
  • Ejecución de 50+ casos de prueba de regresión
  • Testing cross-browser en Chrome y Firefox
  • Validación de interfaz usando Figma
  • Pruebas funcionales de cálculo de precios, rutas y reservas

Resultados obtenidos:

  • Reporte de 15+ defectos críticos
  • Cobertura completa de funcionalidades clave
  • Documentación detallada para futuras regresiones

Herramientas utilizadas:

Jira Google Sheets Figma DevTools Draw.io

🛒 Urban Grocers — QA API Tester

Descripción del proyecto:
API REST para plataforma de comercio electrónico que gestiona productos, kits, servicios de entrega y disponibilidad de almacenes.

Problema a resolver:
Validar la correcta implementación de funcionalidades backend y asegurar la calidad de los endpoints.

Actividades realizadas:

  • Diseño de 35+ casos de prueba
  • Testing de métodos GET, POST, PUT, DELETE
  • Validación de JSON y códigos de respuesta
  • Pruebas positivas, negativas y edge cases
  • Testing de lógica de negocio

Resultados obtenidos:

  • Reporte de 12+ defectos críticos
  • Cobertura del 95% de endpoints críticos
  • Mejora de calidad antes del despliegue

Herramientas utilizadas:

Postman Jira Google Sheets Swagger JSON
