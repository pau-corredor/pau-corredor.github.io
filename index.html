Descripción del proyecto:

Aplicación web de planificación de rutas que calcula duración y precio de viajes para diferentes tipos de transporte (automóvil personal, taxi, bicicleta, scooter, a pie, automóvil compartido).

Problema a resolver:

Garantizar la calidad y funcionalidad de una aplicación crítica de transporte antes de su lanzamiento, identificando errores que podrían afectar la experiencia del usuario y la reputación de la empresa.

Actividades realizadas:

  • Análisis de requisitos mediante mapas mentales y diagramas de flujo
  • Diseño de casos de prueba utilizando técnicas de clases de equivalencia y valores límite
  • Pruebas de regresión ejecutando 50+ casos de prueba predefinidos
  • Testing cross-browser en Chrome y Firefox con diferentes resoluciones
  • Validación de interfaz comparando diseños de Figma
  • Pruebas de funcionalidad para rutas y reservas

Herramientas utilizadas:

Jira Google Sheets Figma DevTools Draw.io
